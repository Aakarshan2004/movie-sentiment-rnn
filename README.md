
# 🎬 Movie Sentiment Analyzer

A Deep Learning based web application that predicts whether a movie review is **Positive** or **Negative** using a trained **Recurrent Neural Network (RNN)**.

## 🚀 Features

- Movie review sentiment classification
- RNN based Deep Learning model
- IMDb dataset
- Text preprocessing and sequence encoding
- 200-token sequence padding
- Prediction confidence score
- Interactive Streamlit web interface

## 🧠 Tech Stack

- Python
- TensorFlow / Keras
- Recurrent Neural Network (RNN)
- NumPy
- Streamlit
- IMDb Dataset

## ⚙️ How It Works

```text
User enters movie review
        ↓
Text preprocessing
        ↓
Word → Integer encoding
        ↓
Padding to 200 tokens
        ↓
RNN model
        ↓
Sentiment prediction
        ↓
Positive / Negative
